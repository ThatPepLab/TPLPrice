PEPTIDE PRICE COMPARISON APP

This folder contains the online RUIC vendor-price comparison.

WHAT IS INCLUDED
- Shared-password access gate
- Product search and strength selection
- China and USA warehouse comparisons
- Landed-cost sorting
- Separate carts for every vendor and warehouse
- Shipping, discount, crypto, and free-shipping calculations
- No Retail PDF feature or PDF pricing logic

ACCESS
- An internet connection is required.
- Enter the shared password when the site opens.
- Access is remembered only for the current browser session.
- The app does not register a service worker or provide offline/PWA installation.

SECURITY NOTE
The password gate discourages casual access. Because this is a static website,
it is not a substitute for server-side authentication.
