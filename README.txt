PEPTIDE PRICE COMPARISON APP

This folder is an installable Progressive Web App (PWA).

WHAT IS INCLUDED
- Product search and strength selection
- China and USA warehouse comparisons
- Landed-cost sorting
- Separate carts for every vendor and warehouse
- Shipping, discount, crypto, and free-shipping calculations
- Offline use after the first successful visit
- No Retail PDF feature or PDF pricing logic

HOW TO USE IT AS AN APP
1. Upload this entire folder to any HTTPS static host, such as GitHub Pages or Cloudflare Pages.
2. Open the resulting web address on the phone.
3. Android/Chrome: choose Install App.
4. iPhone/Safari: choose Share, then Add to Home Screen.

Opening index.html directly from a computer will run the comparison, but browsers
require HTTPS or localhost before they enable installation and offline caching.
